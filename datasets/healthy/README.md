# Healthy Dataset Workspace

Place approved real Healthy FlyGym rollout packages under this directory.

Expected dataset identifiers use the form `Healthy_001`, `Healthy_002`, and so
on. Each completed package must pass the existing dataset and artifact
validators before it is used by analysis or experiment tooling.

Do not commit raw rollout data here unless it has been explicitly curated and
approved. This directory contains no synthetic or placeholder rollout.
