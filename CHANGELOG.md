# Changelog

All notable repository changes are documented here. This project separates
software changes from computational outputs and biological interpretation.

## [Unreleased]

- Prepare dataset campaign directory anchors and research tracking templates.
- Keep real execution gated on the pinned Python, FlyGym, and MuJoCo runtime.
- Preserve the existing frozen evidence and publication artifacts.

## [1.0.0]

- Published the frozen computational Drosophila locomotion framework.
- Included the FlyGym adapter, rollout recording/export, viewer export, static
  viewer bundle, analysis, biomarker, experiment, validation, and release
  tooling already documented in the repository.
- Preserved the final report and frozen evidence chain without adding new
  scientific results.
- Canonical release notes: [`docs/release/v1.0.0.md`](docs/release/v1.0.0.md).

This release does not claim biological Parkinson's disease validation, clinical
utility, or evidence from real flies. Future dataset execution must use the
documented runtime and provenance checks.
