# Literature Curation Workspace

This is an empty, human-managed workspace for collecting notes and review
artifacts from Parkinson-related Drosophila papers. It contains no paper data,
citations, extracted values, or scientific conclusions.

## Directories

- `paper_notes/`: one note file per paper;
- `paper_checklists/`: completed eligibility and extraction checklists;
- `extracted_tables/`: researcher-reviewed table transcriptions;
- `figure_annotations/`: source figure references and annotations;
- `review_logs/`: reviewer decisions, dates, and comments.

Use the templates in this directory for new records. Preserve source
provenance, reviewer identity, and review dates. Do not infer missing values or
write directly to the Phenotype Atlas from this workspace.
