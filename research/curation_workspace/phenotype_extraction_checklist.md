# Phenotype Extraction Checklist

Complete this checklist for each candidate extraction. A checked item must be
supported by a source location or an explicit reviewer note.

- [ ] Assay confirmed
- [ ] Unit confirmed
- [ ] Age confirmed
- [ ] Genotype confirmed
- [ ] Control identified
- [ ] Statistics identified
- [ ] Sample size identified
- [ ] Provenance recorded
- [ ] Ready for Atlas

## Review record

- Paper ID:
- Source page/figure/table/supplement:
- Reviewer:
- Date:
- Status: `pending` / `approved` / `rejected`
- Missing information:
- Notes:

An unchecked item blocks Atlas readiness. Do not fill missing information by
inference from another paper, a visual estimate, or an incompatible assay.
