# Systematic Review Planning Templates

This directory contains internal planning templates for collecting
literature-derived evidence for the Disease Signature Database. It is not a
completed systematic review and it contains no paper records or extracted
values.

## Files

- `review_protocol.md`: scope, eligibility, and review roles;
- `search_strategy.md`: databases and proposed search concepts;
- `screening_form.csv`: blank screening record;
- `eligibility_checklist.md`: inclusion and exclusion checks;
- `extraction_form.csv`: blank phenotype extraction record;
- `quality_assessment.md`: reporting-quality checklist without scoring;
- `prisma_flow_template.md`: unpopulated PRISMA-style flow structure.

## Rules

Researchers must search and download papers using their approved institutional
process. These templates do not crawl, download, parse, or infer evidence.
Every extracted value requires provenance and manual review before it can enter
the Phenotype Atlas or calibration targets.
