# Quality Assessment Checklist

This checklist is a blank assessment form for included papers. It records
whether a reporting item is present; it does not assign a quality score.

For each paper, record `yes`, `no`, `unclear`, or `not applicable`, together
with a page or table reference when available.

- [ ] Peer reviewed
- [ ] Sample size reported
- [ ] Statistics reported
- [ ] Control group reported
- [ ] Raw data available
- [ ] Replication reported
- [ ] Blinding reported, if applicable
- [ ] Study limitations reported

The completed assessment must retain the paper identifier, reviewer, date, and
supporting source reference. Missing information remains `unclear`; it must not
be inferred.
