# Eligibility Checklist

Complete this checklist for each screened record. It is a decision aid, not
an automatic classifier. Record `yes`, `no`, or `unclear` and cite the page,
figure, table, supplement, or metadata source used for the decision.

## Study scope

- [ ] Drosophila model is identified.
- [ ] Relevant gene, genotype, or disease-related perturbation is identified.
- [ ] Study includes a declared control or comparison context.
- [ ] Study reports a locomotion, motor-control, or related behavior assay.
- [ ] Assay definition is sufficiently clear for the proposed use.

## Extractability

- [ ] Outcome definition is reported.
- [ ] Unit or scale is reported, or the absence is explicitly recorded.
- [ ] Sample size is reported.
- [ ] Variance or another uncertainty description is reported, when available.
- [ ] Source location for the value is recorded.
- [ ] Relevant age, sex, temperature, arena, and assay-duration context is available or marked unavailable.

## Evidence handling

- [ ] Full text was checked where required by the protocol.
- [ ] The source is sufficiently identifiable for provenance.
- [ ] The paper is not a duplicate record for the same source.
- [ ] Any conflict or ambiguity has a documented reviewer note.
- [ ] The record is eligible for extraction, or an exclusion reason is recorded.
