# Evidence Levels

The atlas accepts a declared `evidence_level` vocabulary:

- `peer_reviewed_primary`: primary peer-reviewed report;
- `peer_reviewed_secondary`: review or secondary peer-reviewed source;
- `preprint`: pre-publication source;
- `unclassified`: source level not yet classified.

The software validates the label but does not assign it, rank papers, or infer
quality. `quality_score` is curator-supplied metadata; the statistics report
only its declared distribution and never calculates a score automatically.
