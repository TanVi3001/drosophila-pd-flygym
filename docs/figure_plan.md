# Figure Plan

Planning only. No figures are generated by this document.

| Figure | Planned content | Source | Required annotation |
|---|---|---|---|
| Figure 1 | System overview | Repository architecture and declared workflow | Module boundaries, data flow, computational scope |
| Figure 2 | Disease Layer | Disease Layer specification and action-modifier contract | Proxy definitions, healthy identity, parameter semantics |
| Figure 3 | Calibration | Calibration candidates, target mapping, and response surfaces | Target provenance, loss method, uncertainty, calibration/holdout split |
| Figure 4 | Signature Matching | Literature and simulation signatures | Normalization, distance method, shared metrics, unavailable fields |
| Figure 5 | Validation | Repeatability, holdout, sensitivity, and failure results | Seeds, units, uncertainty, exclusion rules |
| Figure 6 | Discussion | Scope, limitations, and future validation pathway | Computational concordance versus external biological evidence |

## Figure production requirements

Every final figure must have:

- a stable figure identifier;
- a source-artifact manifest;
- a reproducible generation command;
- metric names, units, and coordinate conventions;
- uncertainty or an explicit statement that it is unavailable;
- a caption reviewed by the research lead;
- a statement of whether the content is computational or externally validated.

The plans do not authorize creation of placeholder plots or fabricated values.
