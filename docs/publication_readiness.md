# Publication Readiness Checklist

This checklist is a planning aid for a bounded computational study. It does
not imply that publication criteria have been met.

- [ ] Literature
- [ ] Calibration
- [ ] Validation
- [ ] Statistics
- [ ] Figures
- [ ] Tables
- [ ] Discussion
- [ ] Limitations

## Evidence requirements

- Literature records have complete provenance and documented review decisions.
- Calibration and validation are separated and reproducible.
- Statistical methods match the data structure and report uncertainty.
- Figures and tables have source manifests, units, captions, and versioned
  inputs.
- Discussion distinguishes computational concordance from external biological
  evidence.
- Limitations include missing data, assay incompatibility, model scope, and
  unavailable validation.

An unchecked item remains an open publication-readiness issue.
