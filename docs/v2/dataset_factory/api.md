# API

Primary API:

- `DatasetFactory`
- `DatasetFactoryConfig`
- `DatasetFactoryResult`
- `RolloutIndexEntry`

Dataset operations:

- `export_dataset`
- `load_dataset`
- `merge_datasets`
- `incremental_update_dataset`
- `deduplicate_dataset`
- `split_dataset`

Reports:

- `dataset_statistics`
- `coverage_report`
- `quality_report`
- `missing_data_report`
- `write_dataset_reports`
- `render_dataset_card`

Validation:

- `validate_dataset_factory_output`

Demo data:

- `synthetic_demo_dataset`

Scientific scope is always computational. Synthetic demo datasets are clearly
labeled and are not evidence.
