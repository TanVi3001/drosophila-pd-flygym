# API Reference

- `SceneGraph`: Root scene container.
- `SceneNode`: Base node class.
- `Transform`: Local/World transforms.
- `BoundingBox`: Spatial bounds.
- `MeshNode`, `CameraNode`, `LightNode`, `TrajectoryNode`, `AnnotationNode`: Concrete nodes.
- `Skeleton`, `Joint`: Articulation hierarchy.
- `Environment`: Scene properties (skybox, ambient).
- `Material`: Surface traits.
- `Visibility`: Layer filtering.
- `Selection`: Object picking.
- `SceneSerializer`: JSON serialization and deserialization.
