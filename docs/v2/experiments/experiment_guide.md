# Experiment Guide

Canonical experiment definitions:

- Healthy baseline
- Candidate phenotype
- Progression Stage0
- Progression Stage1
- Progression Stage2
- Progression Stage3
- Progression Stage4
- Computational intervention reference
- Robustness benchmark
- Sensitivity benchmark

Each definition records metadata, parameters, random seeds, provenance,
expected outputs, and a configuration hash.

The candidate phenotype is a computational candidate only. It is not a
biologically validated Parkinson's disease model.
