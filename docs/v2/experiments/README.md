# V2 Canonical Computational Experiments

The v2 experiment library defines the canonical computational experiments used
for scientific production. These definitions reuse the completed v2 framework
and do not redesign behavior, gait, open-field, progression, digital twin, AI,
or campaign modules.

Definitions live in `configs/v2/experiments/`. Templates live in
`configs/v2/experiments/templates/`.

The library is computational only. It introduces no biological validation,
disease diagnosis, dopamine equivalence, disease-severity mapping, or
mechanistic claim.
