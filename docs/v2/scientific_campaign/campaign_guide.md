# Campaign Guide

Canonical campaign entries:

- `healthy_baseline`
- `pd_candidate`
- `progression_stage_0`
- `progression_stage_1`
- `progression_stage_2`
- `progression_stage_3`
- `progression_stage_4`
- `intervention_reference`
- `benchmark_suite`

Each entry records:

- metadata;
- deterministic seeds;
- normalized configuration hash;
- provenance;
- output layout;
- planned experiment count;
- conservative scientific scope.

The `pd_candidate` campaign name is a repository label for the frozen
computational candidate. It is not a validated Parkinson's disease condition.
