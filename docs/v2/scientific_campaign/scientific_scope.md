# Scientific Scope

Version 2 scientific production campaigns generate computational datasets and
analysis assets.

Allowed language:

- computational candidate;
- simulated rollout;
- production campaign;
- descriptive statistics;
- similarity matrix;
- clustering;
- artifact integrity.

Disallowed conclusions without future external evidence:

- Parkinson's disease validation;
- biological rescue;
- dopamine equivalence;
- disease severity;
- mechanistic equivalence;
- statistical significance;
- direct evidence from real flies.
