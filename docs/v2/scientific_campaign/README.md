# V2 Scientific Production Campaign

The scientific production campaign layer uses the existing Version 2 framework
to plan, execute, organize, analyze, and validate computational behavior
campaigns.

This layer is not a framework redesign. It reuses the existing behavior
platform, gait platform, open-field metrics, progression engine, digital twin
types, AI platform, and research campaign engine.

The campaign library lives in `configs/v2/campaigns/`. These files are
configuration specifications only; they are not evidence reports.

Scientific scope: all outputs are computational simulation artifacts. They do
not establish Parkinson's disease validation, biological rescue, dopamine
equivalence, disease-severity mapping, statistical significance, or mechanistic
causality.
