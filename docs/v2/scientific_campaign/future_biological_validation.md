# Future Biological Validation

Future biological validation would require external experimental data,
predefined endpoint mappings, and explicit project-owner authorization.

Candidate future work:

- compare simulated walking bouts against adult Drosophila walking data;
- validate pause/freezing endpoints against adult behavioral assays;
- compare turning metrics with experimental angular velocity endpoints;
- evaluate gait coordination only after corresponding biological endpoints are
  curated;
- separate simulation reproducibility from biological claims.

No current production campaign should be described as biological validation.
