# API Reference

The primary API consists of dataclasses that form the FlyStudioProject:
- `Scene`, `Actor`, `Layer`
- `Camera`
- `Timeline`, `Bookmark`
- `Overlay`
- `ViewportLayout`, `ViewportConfig`
- `RendererBase` (Abstract Base Class)
- `AssetManager`, `Asset`
- `FlyStudioProject` (with `to_json` serialization)
