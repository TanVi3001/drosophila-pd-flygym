# Scientific Boundaries

This repository is a computational platform. It can support simulation,
measurement, visualization, analysis, provenance, and artifact packaging when
the required runtime and real inputs are present.

It does not, by software execution alone:

- diagnose Parkinson's disease;
- establish clinical prediction or biomarker validity;
- replace biological experiments or FlyGym validation;
- turn computational labels into biological ground truth;
- justify conclusions beyond the imported data and documented protocol.

Reports must distinguish software checks, simulation outputs, derived metrics,
and biological claims. If an input is missing, report it as unavailable or
waiting. Do not fill it with synthetic values in a research workflow.
